# ADR-007: Promise Tracker refuses rather than guesses

**Status:** accepted

**Decision.** A guidance item is scored only if: spoken by management (speaker-aware chunking), forward-looking, numeric, and mapped to a reported line. Comparisons are refused (*not comparable*) for constant-currency guidance vs INR results, segment-level guidance vs company totals, EBITDA for lenders, and quarter-specific growth targets. Unfinished fiscal years get an *interim* read (YTD vs same quarters last year). Restatements of the same target are grouped as *reiterated*; changed numbers are flagged *revised* with the earlier value.

**Why.** "Promised vs delivered" is only valuable if it is right. An honest *not comparable* with the reason is more useful to an analyst than a confident wrong verdict.
