# ADR-006: Briefing-first interface with one-tap Push → Pull

**Status:** accepted

**Decision.** The landing screen is a ranked briefing, not a chat box. Every card has *Investigate*, which opens Research with the ticker, the filing pinned, and a category-specific question already asked. Chat exists inside Research, but the main flows are taps.

**Why.** The investor's first question each morning is "what changed and does it matter?" — that's a list, not a conversation. Pull is where free-form questions belong, and arriving with context removes typing on a phone.
